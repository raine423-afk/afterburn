# Contributing to Afterburn

Thanks for helping! Afterburn is a community fork of the Nexus Mods app, focused on Cyberpunk 2077.

- **Bugs and ideas:** open an issue in this repository. Please don't contact Nexus Mods about Afterburn.
- **Code:** fork, make your change on a branch, and open a pull request. Build with
  `dotnet publish src/NexusMods.App/NexusMods.App.csproj -c Release -r win-x64 --self-contained false -o publish`.
- **License:** all contributions are licensed under the GNU GPL v3.0, like the rest of the project (see `LICENSE.md`). Add a line to `NOTICE.md` for notable changes.
- **Nexus Mods API rules:** changes must follow the [Nexus Mods API Acceptable Use Policy](https://help.nexusmods.com/article/114-api-acceptable-use-policy). Never commit API keys, and never send requests that identify as another application.
